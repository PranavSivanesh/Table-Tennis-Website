# HWUD Table Tennis Club Website

A responsive website for the Heriot-Watt University Dubai Table Tennis Club.

## Features

- Home page with club achievements
- Photo section for team and match-day moments
- Contact page for the President and Vice President
- Club Instagram and email links
- Membership button linking to the HWUD Council club page
- Mobile-friendly navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
